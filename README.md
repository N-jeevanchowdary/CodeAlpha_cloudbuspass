# Cloud-Based Bus Pass System (CodeAlpha Internship Project)

A secure, web-based bus pass generation and booking system built using **Python Flask**, **HTML/CSS**, and **SMTP_SSL** for automated real-time email ticket delivery.

## 🚀 Features
* **Interactive Booking Interface:** User-friendly web form to enter passenger details, select travel routes, boarding points, and bus service types.
* **Dynamic Pricing & Route Details:** Automatically calculates total fares, travel duration, washroom availability, and amenities based on the selected bus service.
* **Automated Email Dispatch:** Integrates secure SMTP_SSL (Port 465) to instantly dispatch confirmed ticket details directly to the passenger's email inbox.
* **Unique Pass ID Generation:** Generates a unique tracking ID for each confirmed booking.

## 🛠️ Tech Stack
* **Backend:** Python, Flask
* **Frontend:** HTML5, CSS3
* **Email Protocol:** SMTPLIB (SMTP_SSL)

## 💻 How to Run Locally
